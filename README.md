# FLOWBIZ CRM

## Introduction

CRM systems have evolved into essential tools for businesses seeking to streamline sales, marketing,
and customer service operations. Traditional CRM solutions primarily focus on managing customer interactions,
sales, pipelines, and support services. However, the rapid digital transformation has necessitated the integration
of social media marketing into business operations. Many businesses now rely on multiple digital channels to engage
customers, generate leads, and drive sales.

This solution addresses these challenges by offering a comprehensive, integrated CRM system that combines customer
relationship management, sales automation, and social media marketing into a single user-friendly platform.

## Installation instructions

- Clone the repository to your local environment
- Create a separate git branch (this will be done in every subsequent tasks assigned)
- Run

```
    npm install
    npm run dev
```

- After every completion of the task assigned push your code to github and let the others know

NB: Never push to the main branch .
